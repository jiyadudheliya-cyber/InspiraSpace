# InspiraSpace

InspiraSpace is a frontend interior design inspiration and blogging website made for a Web Application Development project.

## Technologies
- HTML5
- CSS3
- JavaScript
- localStorage
- GitHub Pages

## Main Features
1. Responsive navigation
2. Interior inspiration gallery
3. Search and room/style filters
4. Save favourite designs
5. Login and registration form validation
6. Dark mode
7. Materials library
8. Blog section
9. Responsive mobile design
10. GitHub-ready static website

## Run
Open `index.html` in a browser.

## Important
This is a frontend academic project. Account data and saved items are stored in the browser's localStorage. There is no database or backend.

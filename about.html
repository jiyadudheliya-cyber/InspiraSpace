ABOUT INSPIRASPACE

Ideas for spaces that feel like you.

InspiraSpace is a student-built interior design inspiration and blogging website.

OUR PURPOSE

Discover. Save. Design.

We bring room inspiration, material references and simple design stories together in one easy-to-use place.

The project is built with HTML, CSS and JavaScript. Browser localStorage is used for demo account data, saved inspiration and theme preference, so no database is required.

Project Features

  • Responsive frontend
  • Interior inspiration gallery
  • Search and room filters
  • Save favourite designs
  • Login and registration validation
  • Dark mode
  • Interior design blog
  • GitHub-ready static website
